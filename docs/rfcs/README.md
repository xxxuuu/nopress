## 状态说明

| 状态 | 说明 |
|------|------|
| 📝 草案 (Proposed) | 提案正在讨论中，尚未开始实现 |
| 🚧 实现中 (In Progress) | 提案已通过，正在实现中 |
| ✅ 已实现 (Implemented) | 提案已完成实现 |
| ❌ 已拒绝 (Rejected) | 提案被拒绝，不会实现 |
| ⏸️ 暂缓 (Deferred) | 提案暂缓，未来可能重新考虑 |

## RFC 模板

创建新的 RFC 时，请使用以下模板：

```markdown
# RFC XXX: [标题]

**状态**: 草案
**创建日期**: YYYY-MM-DD
**作者**: [作者名称]
**标签**: feature,enhancement,bug,etc

---
```

## 提交流程

1. 创建新的 RFC 文档（使用上述模板）
2. 提交 PR 进行讨论
3. 团队评审并通过后，开始实现
4. 实现完成后更新 RFC 状态为"已实现"
